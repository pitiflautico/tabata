# Tabata Training App

Aplicación de entrenamientos Tabata con algoritmo inteligente de organización de ejercicios.

## Características

- Catálogo extenso de ejercicios de tren superior e inferior
- Algoritmo de organización equilibrada de bloques de entrenamiento
- Sistema de frames visuales para cada ejercicio
- Ratio Tabata clásico 2:1 (40s trabajo / 20s descanso)
- Sistema de progresión personalizada
- IA generativa para crear nuevos ejercicios

## Instalación

```bash
npm install
```

## Ejecutar la app

```bash
npm start
```

## Estructura del Proyecto

```
/src
  /models        - Modelos de datos (ejercicios, bloques, etc.)
  /services      - Lógica de negocio (algoritmo de organización, IA)
  /components    - Componentes reutilizables
  /screens       - Pantallas de la aplicación
  /utils         - Utilidades y helpers
```

## Fases del Proyecto

1. ✅ Concepto general e inicialización
2. 🔄 Catálogo de ejercicios
3. ⏳ Representación visual y frames
4. ⏳ Algoritmo de organización de bloques
5. ⏳ IA generativa para el catálogo
6. ⏳ Entrenamiento y aprendizaje automático
7. ⏳ Integración completa en React Native
